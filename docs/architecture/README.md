# 아키텍처 문서

SY키보드가 어떻게 구현되어 있는지 이해하기 위한 문서 모음이다.
코드를 읽기 전 전체 그림을 잡거나, 특정 도메인의 동작 원리를 확인할 때 사용한다.

| 문서 | 내용 |
|---|---|
| [전체 아키텍처](전체%20아키텍처.md) | 타깃/모듈 구성, VC 계층과 Adapter 경계, 뷰·버튼 계층, 버튼 이벤트 타이밍, Policy 카탈로그, 저장소, 수명주기 |
| [한글 입력 로직](한글%20입력%20로직.md) | 두 버퍼 구조, `HangeulCompositionState` 상태 전이, 종성 복원, 나랏글/천지인/두벌식 차이, 오토마타 |
| [자동완성 로직](자동완성%20로직.md) | 3가지 표시 모드(입력 중 / n-gram / 수식), 예측 엔진 3종, 텍스트 대치/복구, 학습·기록 시점 |
| [삭제와 실행취소 로직](삭제와%20실행취소%20로직.md) | 삭제 확정 파이프라인, 삭제 팬 제스처, 반복 삭제, undo/redo 시스템 |
| [한영 통합 키보드](한영%20통합%20키보드.md) | Adapter 2개 + Coordinator 구조, 언어 결정 규칙, 언어 경계 추적, 엔진 언어 캐시 |

처음이라면 [전체 아키텍처](전체%20아키텍처.md) → 관심 도메인 순서로 읽는 것을 권장한다.
각 문서 끝에는 해당 도메인을 커버하는 테스트 목록과 실행 명령이 있다.

프로젝트 소개·트러블 슈팅·클래스 다이어그램은 저장소 루트의 [README](../../README.md)를,
과거 작업 계획·설계 기록은 [docs/superpowers](../superpowers/)를 참조한다
(superpowers 문서는 현재 동작의 근거가 아닌 이력 기록이다).
